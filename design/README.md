# SitGlow design assets

Visual references for Cursor's Agent and for you. Match the layout, hierarchy, and mood; the exact pixels are not production assets.

> **SitGlow branding wins.** The `screens/earlier-set/` mockups were made under an older working name, **"Desk Habits"**, and some older files use UK wording. Whenever an image shows a different name, UK/EU terms, or copy that conflicts with `docs/brand.md`, use SitGlow branding and the US wording in `docs/` instead.
